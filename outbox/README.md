# outbox/

Drafted applications and outreach land here. Nothing in this directory is
ever sent or submitted automatically — `auto_apply` and `auto_send` are
`false` in `opencode.json`, and no script in this workspace overrides
that. Fahad reviews and sends/submits each item himself, manually and
staggered, one at a time.

Suggested filename convention: `<YYYY-MM-DD>-<employer>-<role-slug>.md`
for an application draft, `<YYYY-MM-DD>-<employer>-<contact-slug>.md` for
an outreach draft. Not enforced — just keep drafts easy to tell apart.
